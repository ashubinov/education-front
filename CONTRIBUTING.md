# Как вносить изменения во фронтенд

Ветка `main` публикуется на сайт для всех пользователей, поэтому напрямую в неё не пушим — только через pull request.

1. `git checkout main && git pull`, затем `git checkout -b moya-zadacha`.
2. Открой `index.html` локально (или запусти бэкенд — он сам отдаёт эту папку) и внеси изменения. Проверь на узком экране телефона и на компьютере, в консоли браузера не должно быть ошибок.
3. Если меняешь `css/app.css` или `js/*.js`, увеличь номер версии `?v=` у этого файла в `index.html` — иначе у пользователей останется старый файл из кэша.
4. Запушь ветку, открой pull request, дождись зелёной галочки CI и одобрения владельца.

Нельзя добавлять ключи, пароли и токены, а также менять адрес бэкенда в `config.js` без договорённости с владельцем.
