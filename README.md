# LearnQuest — фронтенд

Интерфейс приложения для обучения по загруженным материалам. Чистый HTML/CSS/JS, без сборки. Работает на **GitHub Pages**,
данные и ИИ — в бэкенде ([education](https://github.com/ashubinov/education), деплой на Amvera).

## Подключение к бэкенду
Адрес бэкенда задаётся в [`config.js`](config.js):

```js
window.LQ_API = "https://<проект>.<пользователь>.amvera.io";
```

Для быстрой проверки без правки файла откройте сайт один раз с параметром `?api=https://адрес-бэкенда` — адрес запомнится в браузере.

Авторизация — JWT: после входа токен хранится в `localStorage` и передаётся в заголовке `Authorization: Bearer …`. Куки не используются.
На бэкенде в `CORS_ORIGINS` должен быть адрес этого сайта: `https://ashubinov.github.io`.

## Публикация на GitHub Pages
1. Репозиторий должен быть **публичным** (в нём нет ключей — только код интерфейса).
2. Settings → Pages → *Build and deployment*: Source = **Deploy from a branch**, Branch = `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется на `https://ashubinov.github.io/education-front/`.
4. Любой `git push` в `main` обновляет сайт.

## Локальный запуск
Положите этот репозиторий в папку `front/` рядом с бэкендом — бэкенд сам раздаёт его на `http://127.0.0.1:8000` (адрес API подставляется автоматически).
